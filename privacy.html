1. 이 프로그램이 하는 일

「들렁모루 업로드」는 음식점 들렁모루가 직접 운영하는 내부용 프로그램이에요. 들렁모루의 구글 계정으로 로그인해, 들렁모루 유튜브 채널에 가게가 직접 만든 짧은 소개 영상을 올리는 일만 해요. 다른 사람은 이 프로그램을 쓰지 않아요.

2. 쓰는 정보

  • YouTube API 서비스(YouTube API Services)를 통해 들렁모루 채널의 기본 정보(채널 이름·ID)를 읽어 올바른 채널인지 확인해요.
  • 영상을 올릴 때 가게가 만든 영상 파일과 제목·설명·태그를 YouTube로 보내요.
  • 로그인 허용 정보(토큰)는 가게 컴퓨터 안에만 저장돼요. 다른 곳으로 보내거나 팔지 않아요.
  • 손님, 시청자, 다른 유튜브 사용자의 개인정보는 모으지도, 저장하지도 않아요.

3. 보관과 삭제

토큰은 프로그램이 동작하는 동안만 가게 컴퓨터에 보관하고, 필요 없어지면 지워요. 언제든지 Google 계정 → 보안 → 서드 파티 연결에서 이 프로그램의 접근 권한을 취소할 수 있어요. 취소하면 가게 컴퓨터에 남은 토큰도 더는 쓸 수 없어요.

4. 제3자 서비스

이 프로그램은 YouTube API 서비스를 사용해요. 이용자는 YouTube 서비스 약관의 적용을 받으며, 구글의 정보 처리에는 Google 개인정보처리방침이 적용돼요.

Privacy Policy (English)

App: "Deulleongmolu Upload" (들렁모루 업로드). Effective November 13, 2026.

What it does. An internal tool operated by Deulleongmolu, a restaurant in Seogwipo, Jeju, Korea. It signs in with the restaurant's own Google account and only uploads the restaurant's own short promotional videos to the restaurant's own YouTube channel. It is not offered to any other user.

Data accessed. Through the YouTube API Services, it reads the basic information of the restaurant's channel (channel title and ID) to confirm the correct channel, and sends video files with titles, descriptions and tags created by the restaurant. OAuth tokens are stored only on the restaurant's computer and are never shared, sold or sent elsewhere. No personal data of customers, viewers or other YouTube users is collected or stored.

Retention and deletion. Tokens are kept only while the tool is in use and deleted when no longer needed. Access can be revoked at any time at Google Account → Security → Third-party connections.

Third parties. This app uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google Privacy Policy applies.
